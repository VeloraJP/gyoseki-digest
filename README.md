# 業績ダイジェスト

登録した決算（年次）と月次の数字を自動で要約し、「結局いくら儲かるのか」「儲けが増えた／減った要因は何か」「前月・前年同月・前年度と比べてどう変わったか」に、追加の数値入力なしで答えるWebアプリです。

根本原則：**全ては、会計がわからない中小企業経営者のためにある。**

仕様の正本は `~/workspace/projects/management-analysis-tool/業績ダイジェスト_仕様書.md`（2026-11-06承認の正式仕様）です。本リポジトリは初版範囲を実装し、発展フェーズとして「目標と進捗」「business-tool2-2形式JSONの移行」「削除機能」を、追加フェーズとして「損益分岐点」「推移グラフ」「1枚サマリー」「利益と手元のお金のズレ」を追加しています。試算フェーズとして、簡易シミュレーション正式10種をその場入力の「試算」エリアとして追加しています（実機受入・承認待ち）。

## 特徴

- スマートフォン・PC両対応のWebアプリ（PWA構成）。ビルド不要のプレーンなHTML/CSS/JavaScript（ESモジュール）。
- データは端末のブラウザ内（localStorage）にだけ保存し、サーバーへ送信しません。
- バックアップと端末間移行はJSONの書き出し・読み込み（置き換え方式、5MBまで、本ツール形式のみ）。
- business-tool2-2形式のJSONは、移行専用の導線から変換内容を確認したうえで、新しい会社として追加できます（置き換えはしません）。

## 初版の範囲

- 会社登録と初回設定（決算月・税込／税抜・金額入力単位）
- 年次登録：簡易2項目（売上高・当期純利益）／標準17項目の2段階、貸借対照表（B/S）は任意登録
- 月次登録：7項目（売上高、売上原価、人件費合計、地代家賃、その他固定費、その他変動費、当期純利益）
- 自動業績分析：当期純利益の主表示、前期比較、増減の大きい項目（要因リスト、上位5項目）
- 月次・年度レビュー：前年度・前月・前年同月比較と当年度累計
- SIM-06発展系①「差額・達成率」は後段フェーズのため初版には含みません。

## 発展フェーズの範囲

- 目標と進捗：年次期ごとに目標利益（当期純利益／経常利益／営業利益、既定は当期純利益）を保存し、対象期の年次標準登録から必要売上高・差額・達成率を表示。経常・当期純利益の目標は対象期の実績構造で営業利益へ換算し、当期純利益ベースは「概算」と明示。
- 月次進捗：目標期の翌期の月次累計と目標を比べ、進捗率・残り・「月平均あと売上◯円」を表示。月次が無い場合は表示しない。
- 複数案の比較（限定形）：同じ基礎データのまま目標額だけを変えた最大3案のその場比較（保存しない）。
- ホーム画面に、目標を設定した会社だけ「目標まであといくら」の要約を表示。
- 移行：business-tool2-2形式JSONを判定し、年次標準登録（詳細P/L・B/S）へ変換。確認画面で対応を表示し、明示操作で新しい会社として追加。
- 削除：会社・年次期・月次記録の削除（確認の操作を挟む）。

## 追加フェーズの範囲

いずれも登録済みデータだけで表示し、新しい入力項目は追加していません。

- 損益分岐点：目標と進捗画面に「赤字にならない最低限の売上」（固定費÷限界利益率）と、現在の売上との差を表示。計算できない期では枠と理由を表示。
- 推移グラフ：月次・年度レビューに、売上と利益の推移の棒グラフを表示（月次は直近12か月まで）。登録が2件未満では理由を表示。
- 1枚サマリー：当期純利益・前期比較と要因の要点・目標と進捗・損益分岐点・現預金の増減を1画面に集約し、印刷・共有に使える形に（既存表示の再配置のみ）。
- 利益と手元のお金のズレ：B/Sを2期分登録した会社向けに、利益と現預金の増減の差の主な内訳（当期純利益、減価償却費、売掛金・棚卸資産・買掛金・借入金の増減、その他）を、業績を見る画面で実績データにより説明。将来の予測ではなく、「主な項目だけの説明」である旨を明示。

## 試算フェーズの範囲

経営分析Proの簡易シミュレーション正式10種を、総整理の仕様をもとに本ツールの流儀で作り直した、その場入力の試算エリアです。

- 10種：商品・サービス価格／損益分岐点／人件費／借入返済／投資回収・利回り／資金繰り／財務健全性／収益性比率／成長率／給与・雇用コスト。
- 会社の登録がなくても手入力だけで計算でき、会社を開いている場合は登録データ（年次優先、月次12か月がそろえば月次集計で補完）が初期値として入り、その場で書き換えられます。
- 試算の入力は保存されず、会社情報へも反映されません。入力画面と結果画面を分け、結果から入力に戻っても入力値は保持されます。
- 出せない結果は「―」と理由を表示し、計算の考え方（式）を結果画面に示します。経営の良否を断定する表示はしません。
- 資金繰りの試算は、入力した月の収支が続く仮定の簡易な目安であり、詳細な資金繰り予測ではありません。試算の損益分岐点は、登録データから表示する損益分岐点（目標と進捗画面）とは別物として、結果画面に注記します。

## 起動方法

任意の静的HTTPサーバーでこのフォルダを配信してください（ESモジュールのため `file://` では動作しません）。

```bash
cd gyoseki-digest
python3 -m http.server 8123
# http://localhost:8123/ を開く
```

## テスト

npm test   # node --test（計算・比較・検証・保存・描画のテスト）
